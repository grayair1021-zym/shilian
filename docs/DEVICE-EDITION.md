# 地图与随身设备版

## 单人任务

开始界面默认为“单人任务”。该按钮始终调用本地引擎创建 `mode: solo` 的完整世界，不探测服务、不等待搭档、不提交支援留言。舱门、扫描和供电都由玩家直接控制。双人联机仍通过同一套动作层和 MCP 运行。

单人流程：

1. 点击亮起的相邻舱室走一段。锁门时会在设备上选中该门，点击“解锁”后再点目标舱室。
2. 要先扫描邻舱而不是进去，用右键、Shift+点击或触屏长按选择目标，再在设备上操作。
3. 翻找、静听、屏息仅在设备下方三个实体键提供。任务与下一步建议只展示信息，不提供另一套执行入口。
4. 地面栏点击拾取；背包槽选择物品后，屏幕显示使用或放下按钮。
5. 配电阀复位之后，选中逃生舱，拨动对应分区的供电开关。完成任务，再从地图走到逃生舱并启动撤离。

不再有相邻通道列表、房间选择下拉框、地图上的大块上下文弹窗、多个重复翻找按钮。任务、生命体征、下一步建议和事件记录常驻在设备上。历史事件用前后键翻页，正常桌面游玩不需要滚动整页。

## 实际机制变化

- 开局随身一罐备用氧气。轻度异常在站内另外放六罐，其他难度另外放五罐，分散到不同房间。
- 同一舱室重复翻找不扣回合或资源。
- 静听增加两次轻步机会：移动不增加常规脚步噪声，遭遇时可以消耗全部剩余预判避开一次擦撞。撬门仍会产生噪声，静听不是无敌。
- 静听的可疑来路标在地图门线上，并进入路径建议的风险权重。线索移动后失效，静止时最多参考三个回合；不会保证未来一定安全。
- 刚完成静听时重复点击不扣费。
- 防护服破损使用 `suit` 音画事件：红色边缘短闪和高频短促报警；结构断裂使用 `fracture`：地图震荡、低频结构声。两者不共用氛围的十八秒冷却。
- 地图上的所有覆盖效果均穿透鼠标；不显示挡住房间的文字字幕。降低氛围强度仍可减弱动态效果。
- 单人生成时避免配电阀损坏的回路内部出现双侧锁死门；撬棍、工具包必须可在不经过机械卡死门的区域找到。

## 验证入口

设置 → 操作说明 → 开发检查可运行独立测试局，不改动正在玩的任务。新增测试覆盖单人创建、氧气数量、随机种子、门锁/供电、重复动作不扣费、轻步预判、两类警报和只读建议。

命令行回归用例：

```sh
npx tsc --noEmit -p tsconfig.tests.json
npx tsx --test tests/device.test.ts tests/atmosphere.test.ts tests/mcp-atmosphere.test.ts
```

升级后重启联机服务并创建新局，新局含 `quietSteps` 等状态字段。普通地图滚轮不缩放；缩放只用控件或 Ctrl/Command+滚轮。

构建通过不等同于真人验收。仍需测试者在 1366×768、1440×900 下检查所有设备按键可见性，并在真实耳机/音箱上试听两种警报。手机竖屏保留可滚动降级，不通过极小字号硬塞整台设备。
