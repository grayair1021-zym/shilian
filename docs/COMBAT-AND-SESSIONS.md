# 2026-09-16 战斗与联机会话修订

## 攻击的价值

保留非对称信息与生存压力：怪物隐藏生命初始为 100，不向现场或远程视图暴露数值。徒手造成 10 伤害、撬棍 30、密封胶 5、无人机 45；各自原有命中概率保留。密封胶偏向控制，撬棍与无人机偏向伤害。

普通休整窗口为基础控制回合（徒手 1、撬棍／无人机 2、密封胶 4）加上每累计损失 25 生命增加 2 回合；生命降至 0 时，进入 10 回合失能，而非永久死亡。窗口不包含攻击本身的结算回合。休整结束恢复 25 生命且至少恢复至 35。危险环境仍会伤害现场员。

怪物退避沿可通过的相邻舱门最多走两步，不随机传送；无路时在原地失能。首次伤到 40 生命或以下时，交战舱掉落一块备用电池，每局最多一次，需要现场员拾取。游戏只通过伤势描述、动作和冲击回执反馈，不显示怪物血条。

无人机冲击限当前舱或可通行的相邻舱，省略目标只使用无人机当前舱，不读取怪物位置来自动索敌。目标错误、距离过远、通道阻塞或资源不足则拒绝；有效冲击即使没有命中也耗电和回合，报告已执行但未确认命中。过载损毁概率保留为 40%。

## 联机约定

- 所有远程写工具必须携带明确 `run_id` 和 `round_id`，先读取 `game_status` 返回的 `runId`、`roundId`。Schema 为兼容错误提示允许省略，但服务端拒绝缺失值。
- 原地重开保留 run ID 和现场令牌，生成新的 round ID；旧轮指令不执行。前端收到新轮同步时重置呈现状态与计时。
- 返回首页会经认证结束旧局；从同一浏览器会话另开新任务时，认证替换旧局。旧编号和旧 WebSocket 均不能继续行动。服务内保留旧记录直到进程退出，不提供可操作入口。
- 多局并存时，省略 run ID 不再默认选最新局，要求与现场员核对。
