# 失联之后：信息关系恐怖

升级后请重启联机服务并新建一局。已有进程不会自动加载新的事件类型与状态字段。

## 这次的边界

恐怖来自同一事件的不同片段，而不是由程序偷偷杀死角色、伪造消息或反转玩家指令。未知目标没有在界面上出现的真名。片段允许推理，不能当作身份鉴定。

- `WorldState.atmosphere` 只在引擎中保存完整的配对事件和节拍。
- 浏览器只接收 `fieldEffects`：已经发生在现场的文字与音画提示。
- MCP 的 `operator_view` 接收 `disturbanceFragments` 和 `advisories`，不接收现场片段。
- `advisories.authoritative` 恒为 `false`。旧值班评估并非命令，也不代表程序知道操作员的思考。
- 每个写入型 MCP 工具返回 `confirmation`，包含对局、结算回合、实际操作说明、当前资源、门态与供电。错误仍通过 `isError` 如实报告。
- 通讯消息的署名、内容和历史日志不会被氛围系统替换。未发送的现场信息不会被拿去吓远程席。

## 游戏内可见的变化

| 时机 | 现场员得到 | 远程席得到 |
|---|---|---|
| 导航/观测舱附近出现接近迹象 | 玻璃上短暂的五指形清亮区 | 同位置外壁热探头的一次近距脉冲 |
| 邻舱传来五次敲击 | 声音方向与回应选择 | 与泵组周期不符的五个振动峰值 |
| 在邻近动静前停步 | 隔墙刮擦声同时停止 | 运动波形中止，不能判定已经离开 |
| 冷凝雾遮挡 | 像管道又像站立物的轮廓，移动头灯后消失 | 回波重叠，轮廓拟合失败 |
| 重返已记录细节的舱室 | 杯口、检修牌或安全带的朝向似乎不同 | 上次采样后有微小姿态漂移 |
| 翻起带线索的纸页 | 背面新增可读句子，原来的记录不变 | 旧扫描座的触点变化与缺页记录 |
| 标记之后继续行动 | 风管传来一次短响 | 标记区域的一次应力短脉冲，不等于事故 |

这些事件不会把背包物品移走，也不会因为标记“危险”而制造一场真实事故。双方需要自己描述并拼接时间、位置和来源。结束报告才把两边原文并排显示，不替玩家宣布怪物身份。

## 节奏

- 前 4 回合不安排叙事惊扰，首次候选节拍在第 5 至 8 回合。
- 叙事事件后通常保留 5 至 10 回合的安静；轻度异常最少 7 回合。
- 舷窗事件每局最多一次，敲击最多两组。重返变化、雾影和风管声也有次数上限。
- 前端额外设置 18 秒音画间隔。快速操作不会把所有被跳过的特效排队补播。
- 声音先出现，视觉延后约 420 毫秒。震动仅作用于地图，最大位移约 1.5 像素。
- 暂停、打开设置/说明、页面进入后台、任务结束均停止氛围播放。重连不重播历史惊扰。
- 普通滚轮仍然滚动页面，氛围覆盖层不拦截鼠标和触屏操作。

## 敲击选择

敲回去消耗 1 回合并增加噪声。目标不瞬移，至少留出后续行动机会，仍须遵循舱门与通道规则。不回应不消耗回合，也可以直接离开。敲击只在当前舱室短暂有效，过期后不能补答。MCP 没有代替现场员回答的工具。

## 给远程操作员的压力

核验累计达到一定次数后，旧值班模块可能列出实际扫描/追踪次数、回合与电力开销，然后问：

> 你是在等一条新证据，还是等一次保证？

这是游戏内的非权威评估，可以不采纳。它不读取对话之外的意图，也不会惩罚玩家免费查看视图。信号延迟或干扰时，回执显示缓存可能留有一个未补全的字；文本明确说明没有对应调用，最终确认区仍然正确。没有“实际解锁，系统却偷偷锁门”的实现。

## 舒适度

菜单提供“标准 / 减弱 / 关闭”。系统偏好减少动态效果时，默认使用减弱设置，并停用抖动。音效开关仍独立有效。关闭音画不会删线索、改变种子或影响后续事件。

## 回归检查

页面内：菜单 → 玩法说明 → 开发检查 → 运行本地自检。该按钮只使用独立测试局，不触碰正在游玩的任务。

命令行：

```sh
npx tsc --noEmit -p tsconfig.tests.json
npx tsx --test tests/atmosphere.test.ts tests/mcp-atmosphere.test.ts
```

第二项使用真正的 MCP SDK 内存传输测试工具调用、来源隔离、最终确认和现场广播；它不是 HTTP、stdio 或真实浏览器测试的替代品。

交测时请另行验证：

1. 在 1366×768、1440×900 和触屏设备上，从地图滚动、点选房间和处置敲击。
2. 特效出现时操作按钮，确认覆盖层不会抢点击；雾影在移动头灯时消失。
3. 播放音效后暂停、静音或切到后台，确认声音及时停止。
4. 断开重连，确认旧敲击、旧手印不会自动重播。
5. 对比同一事件的 FieldView 和 OperatorView：现场文本不能出现在远程 payload 中，反之亦然。
6. 检查最终门态与资源；即使终端评估催促，也不能有未请求的副作用。

本轮代码构建不等于完成真人恐怖节奏、浏览器音频兼容性或网络部署验收。
